# USDT artwork and font provenance

The decorative bitmap artwork was extracted from the **user-supplied approved
reference**, `codex-clipboard-a54c5eb5-c902-4c1d-bf12-e72dd2355165.png` (1122 × 1402).
This is a transformation of artwork supplied for this implementation, not an
assertion that exchange trademarks are open-source or that the marks certify any
market data. No proprietary font is embedded or extracted from that image.

Only the following source rectangles are retained, in source-image pixels
`(left, top, right, bottom)`. They contain no prices, exchange names, dates,
timestamps, percentages, or summary values. The complete flattened poster is
never loaded by the production renderer.

These are the supplied illustration's versions of the exchange marks, not a
newly obtained official vector brand kit. Some current public exchange marks
have since changed; substituting those would reduce fidelity to this reference.
The fallback for **AbanTether**, or an unavailable known logo, is its Persian
exchange name alone. Never substitute an invented icon or letter badge.

The crops retain the source's raster resolution. A supplied licensed vector
brand kit or original layered artwork can replace them without changing the
data layout. Do not enlarge the original poster to extract sharper details.
