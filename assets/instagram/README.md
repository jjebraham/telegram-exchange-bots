# Instagram artwork

`kiani-logo.svg` is a vector transcription of the Kiani Exchange monogram
supplied by the user. It is displayed in dark green, large on the Feed cover
and beside the brand name on each subsequent slide. Its geometry is rendered
directly with Pillow, so no additional SVG runtime is required.

Country flags and pictograms are unmodified Twemoji 14.0.2 graphics
by Twitter, Inc. and other contributors, combined into a PNG atlas.
Source: https://github.com/twitter/twemoji/tree/v14.0.2/assets/72x72
